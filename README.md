# Education-de-la-fran-ais-
Utiliser l’intelligence artificielle pour améliorer l’enseignement et l’apprentissage du français, créer des supports pédagogiques interactifs, préparer des exercices adaptés aux différents niveaux des élèves et développer les quatre compétences linguistiques : compréhension orale, compréhension écrite, production orale et production écrite.
